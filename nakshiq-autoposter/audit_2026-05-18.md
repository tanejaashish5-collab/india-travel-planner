## 🔥 Likely root causes (ranked)

1. **GH Actions push-rejection / branch race.** Multiple commits to `main` on
   2026-05-17 (the Tier 7 refactor) likely raced with autoposter runs that try
   to push `chore: autoposter state ...` to the `autoposter-state` branch. If
   `git push` returned "rejected — non-fast-forward" the workflow would log
   the error but the post would already be live on Instagram/Facebook.
2. **Watchdog also silently dropped.** The watchdog workflow's own comments
   note it silently missed fires on 2026-05-15. If both autoposter and watchdog
   are skipping low-traffic UTC windows, dropped slots compound.
3. **Tier 7 refactor introduced a regression** that crashes after Outstand
   publish but before state-push (matches the tirthan-valley "publish happened,
   but flagged later" pattern).
4. **`AUTOPOSTER_PAT` secret expired / scope changed**, blocking the watchdog
   from dispatching catch-ups.
