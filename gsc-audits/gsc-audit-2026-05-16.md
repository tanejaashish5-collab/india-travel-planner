## 5. Trajectory & action items

### Wins (carrying over from 5/15)
- **Indexed page count holding at 14.8K** — the 7.8K gain vs Apr 20 (+111%) is durable, not a transient spike.
- **Discovered-not-indexed bucket holding at 4,993** — was 11,568 on Apr 20. The internal-linking / hub-page strategy continues to convert.
- **Position 9.5 still ~3 rungs better than Apr 20** (12.4 → 9.5) despite the recent click pullback. Ranking integrity intact.

### Concerns
- **Three consecutive days of click decline** (128 on 5/13 → 115 on 5/15 → 107 today, all 7-day totals). The drop is consistent with the 5/1–5/7 high-volume window rolling out of the trailing-7d view, but the slope is steep enough to warrant tracking. If 5/17 lands below 100, the "window slide" explanation gets weaker.
- **Position drifted 9.3 → 9.5** — first uptick since 5/13. Still small in absolute terms but worth watching against the click decline; if both worsen together, that's the early signature of an actual ranking issue.
- **GSC indexing data has not refreshed in 5 days.** Last update 5/11/26. This is at the outer edge of normal cadence — not a problem yet but limits insight into how the 5/12–5/15 site activity affected the index.
- **404 validation still Failed (26 URLs, unchanged).** The Apr 20 validation has now been failed for ~26 days. Time to either re-submit or pull the URL list manually — the bucket is small enough that a one-sitting fix is realistic.
- **"Page with redirect" still 2,679, flat for 3 audits in a row.** The locale-prefix migration redirect bucket is not draining. Worth confirming that the 307→301 conversion in `src/middleware.ts` is firing for these specific URLs.

### What's working (don't change)
- Hindi (/hi/) page over-performance is now a sustained 3-audit pattern (5 → 5 → 6 of top 10). Whatever's driving this — Hindi-locale query strength, less competition on Hindi destination/month, or something structural — should not be disturbed.
- Low-volume long-tail (destination + month) keeps surfacing new queries each audit. The content shape is doing its job.

### Priority action queue
1. **Re-submit the 26-URL 404 validation** — unchanged from 5/15 action queue. The bucket is small; the validation has been Failed for ~4 weeks; a fresh sitemap check + URL inspection on the 26 URLs is a 30-minute task that closes the longest-standing open item.
2. **Title/meta optimisation on the two 0.3–0.5% CTR / 500+ imp pages** — now `/hi/destination/darjeeling/may` (679 imp, 0.3% CTR) and `/en/destination/munnar/june` (571 imp, 0.5% CTR). Flagged for the third straight audit. Single highest-leverage CTR lever.
3. **Audit "Page with redirect" 2,679 bucket** — confirm 301 vs 307, confirm targets are indexable. Has been static for 3+ audits.
4. **Watch tomorrow's clicks number.** If 5/17 lands ≥110, the recent dip was just the window slide and we can stand down. If it lands <100 with position drifting further, investigate ranking/CTR loss specifically.
