## What it IS worth reading for

**1. Token cost is the industry's main story — and the one free win needs no vendor.**
Eight data points in six weeks, but **only one is independent and directly applicable:**
*compiling stable agent instructions to deterministic code cut token use by 94%* (07-15),
keeping the model only for judgment-heavy steps. Several NakshIQ automations are still prose
instructions for entirely deterministic work (audit commit/verify sequence, SOS re-verify
loop, ledger merges) — every run re-derives fixed steps at token cost. **This is the one
actionable free item from the whole sweep.**

⚠️ **Evidence hygiene, already labelled in the doc:** of the eight router/cost numbers, five
are **vendor self-reports** (Cursor 60%, Devin 35%, Ramp 30%, Deep Agents 65%) and **two are
paid sponsor placements** (Viktor $11.35→$2.07, CData 97.6%). *The direction is corroborated
by many independent parties; every headline magnitude is marketing.*

⚠️ **Counter-signal in the same corpus:** routing becomes a systems-optimisation problem
where caching dominates base price, and **prompt caching is fragile** (07-27) — *"a changed
tool definition, a model switch, or a provider routing decision can turn a cheap incremental
request into a full replay of the context."* A router that switches models mid-session can
therefore *cost more*. **Do not adopt routing as a reflex.**

**2. Anthropic's guidance now contradicts the house prompting style.** *"The new rules of
context engineering for Claude 5 generation models"* (07-27): models *"prioritize judgment
over strict rule-based context engineering… progressive disclosure helps optimize context
usage by loading necessary information on demand, while simple tool descriptions replace
repetitive instructions."* Independently validates the 2026-07-27 dashboard cleanup (63 KB →
8 KB) and the existing *"say less, not more"* Fable rule — and implies remaining long
itemised rule-lists work **against** the current model generation.

**3. Cheap/local capability landing on live assets.** Mistral OCR 4 (170 languages, single
container, strong on low-resource languages) · Fish Audio S2.1 Pro (83 languages) and
MAI-Voice-2-Flash — both relevant to the Hindi TTS stack · Qwen-Image-3.0 (native rendering
of 12 languages) — relevant to Devanagari-title images under the no-English-overlay rule.

**Gratifying confirmation, no change needed:** *"I burned all my tokens researching how to
save tokens"* (07-20) concludes *"use cheap models to find information, accurate models to
verify it, and deep research last"* — already our standing Haiku-scouts / Opus-orchestrator
rule.
