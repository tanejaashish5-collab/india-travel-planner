# Brian Casel

Solo bootstrapper running his own business on Claude Code agents. Studied via 3 of his agent-operator pieces (rest of his catalog overlaps what we already run — not a full-channel audit).

## The agent-in-a-box model

Sell the TEMPLATE + install + retainer, not a one-off build: one-time install **$2–10K**, retainer **$500–2K/mo** — maintenance is real revenue, not padding, because the business changes, models improve, and edge cases keep appearing. Same tripwire-then-retainer shape as [[jason-lemkin]]'s enterprise-agent economics and [[corey-ganim]]'s concierge retainer, at bootstrapper scale — see [[retainer-is-the-business]].

## Night-shift pattern

Interface (a markdown file or small app) + a scheduled skill + short human reviews (2–20 min) — the agent works overnight/off-hours, the operator reviews in a short daily window. Matches our own night-shift launchd fleet almost exactly (see [[self-hosted-agents]], [[claude-code-ecosystem]]) — this is the confirmation-not-news share of the study.

## Training curve

Daily feedback for the first ~30 days, then weekly once the agent's error rate stabilizes. Directly reusable for our own agent onboarding (matches Corey Ganim's exemplar-feedback loop in [[src-ganim-ai-assessment]] — first 2–3 outputs 60–70% right, near copy-paste by #5).
