# Test cheap before build (the universal rule)

**The pattern:** every operator studied — Greg Isenberg, Hormozi, Marina Mogilko, Codie Sanchez, the Netflix founders, Basesh Gala — converges on the same rule: validate with money or hard signals BEFORE building. "Money is truth serum" ([[strategist-checklist]]).

## The concrete versions banked

- **Presell** (Isenberg): 30-sec prototype + ~300 emails + 50–70% founding discount = de-risked launch with real cash.
- **Sell 1:1 high-ticket FIRST** (Hormozi/Dan Koe): $1K × 10 buyers = 3× the profit of $100 × 90, and 10 conversations teach more than 1,000 signups. Value equation: Dream Outcome × Likelihood ÷ (Time Delay × Effort) — latency beats magnitude.
- **20–30 user interviews** before any build (Marina).
- **$0 14-day content tests with explicit kill gates** (our content-engine spec, 2026-06-15): e.g. Guna Code's 4-week gates, hill-station quiz's <50-completions/14d kill gate. A test without a pre-written kill gate is not a test.
- **Founder-profile encoding:** portfolio = 2–3 cheap parallel DEMAND TESTS, never parallel builds.

## The standing diagnosis it answers

2026-06-23 finding: Ashish's constraint is NOT missing ideas (15+ builds exist) — it's that **not one has a proven KPI or first ₹/USD**. The bridge from idea-surplus to execution is always the cheapest possible test, run to its gate, with the gate honoured. The `/council` skill (from [[nate-herk]]'s gold finding) formalizes exactly this: verdict + cheapest 48-hour test.
